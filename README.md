# Site de Casamento - Julio & Grazielly

Site com confirmacao de presenca (RSVP), mural de recados e painel do casal.

- Pagina do convidado: confirmacao de presenca, acompanhantes, recado e botao Como Chegar (Google Maps)
- - Area do casal (rodape): usuario `casal` - estatisticas, convidados, checklist, orcamento, recados e configuracoes
  - - Banco de dados: Firebase Firestore (config em firebase-config.js, regras em firestore.rules)
    - - Hospedagem: GitHub Pages
